# Raw CAD

Original STEP/STP files whose licence permits public distribution, exactly as downloaded. Never
edit or overwrite these. Convert copies with `tools/cad/step2glb.py` instead.

The folder is empty: no file could be downloaded from the build environment. See
[`../SOURCES_AND_LICENSES.md`](../SOURCES_AND_LICENSES.md).

Files whose licence does not permit publication go in `../restricted/`, which git ignores.
