# Anatomy kit (vendored)

`iso-kit.mjs` and `lathe.mjs` are copied unchanged from the open-source Anatomy kit,
github.com/wheresryan22/anatomy, commit `1482e8469b0a9e0d8cc18ea2740a01423d29ae80`,
under the MIT licence in `LICENSE`. They are used by `../scanhead.mjs` to build the
scan-head figure, and are inlined into `anatomy.js` for the page.
